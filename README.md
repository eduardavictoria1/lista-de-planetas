# Lista de Planetas

Projeto desenvolvido em Python para a disciplina de Estrutura de Dados do curso de Engenharia de Software.

A proposta da atividade foi desenvolver uma aplicação interativa no estilo CLI utilizando uma estrutura de dados do tipo lista.

Como tema, foi escolhida uma lista de planetas.

## Funcionalidades

- Adicionar planeta
- Adicionar planeta em uma posição específica
- Remover o último planeta
- Remover planeta por posição
- Mostrar os planetas cadastrados

## Estrutura de dados

O projeto utiliza uma implementação própria de `ArrayList`.

Foram utilizados métodos para:

- Inserção de elementos
- Remoção de elementos
- Controle das posições
- Verificação da capacidade da lista
- Aumento da memória
- Cópia dos elementos para uma nova lista
